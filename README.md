# Apex Urban Fitness Studio

## Project Overview

Apex Urban Fitness Studio is a fictional boutique fitness organisation established in 2021 in Midrand, Gauteng.

The website was created as a student web-development project to demonstrate HTML5, CSS3 and JavaScript skills.

---

## Organisation

### Organisation Name

Apex Urban Fitness Studio

### Established

2021

### Location

Midrand, Gauteng, South Africa

### Mission

To inspire healthier lifestyles by delivering premium, personalized fitness experiences, cutting-edge equipment, and an inclusive community environment.

### Vision

To be Midrand's premier boutique fitness destination known for transformative health results and dynamic community culture.

### Target Audience

- Working professionals aged 22–50
- Health-conscious local residents
- Corporate teams looking for group fitness packages

---

## Website Goals

The main goals of the website are:

1. Encourage free trial class bookings.
2. Present membership packages.
3. Provide an interactive class timetable.
4. Capture customer enquiries.
5. Provide studio contact and location information.

---

## Website Pages

### Home

`index.html`

The homepage introduces Apex Urban Fitness Studio and provides calls-to-action for booking a free trial and viewing memberships.

### Class Timetable

`timetable.html`

Contains an interactive class timetable that allows visitors to filter classes by:

- HIIT
- Pilates
- Boxing
- Personal Training

### Memberships

`memberships.html`

Displays three membership packages:

- Basic
- Unlimited
- VIP Personal Coaching

The page also contains a JavaScript membership calculator.

### Trainers & Gallery

`trainers.html`

Displays fictional trainer profiles and a studio gallery section.

### Contact & Booking

`contact.html`

Contains:

- Two fictional studio locations
- Contact information
- Opening hours
- Free trial booking form

## JavaScript Features

The website includes the following JavaScript functionality:

### Mobile Navigation

The navigation menu can be opened and closed on smaller screens.

### Active Navigation

The current page is automatically highlighted in the navigation menu.

### Timetable Filtering

Users can filter classes by class type.

### Membership Calculator

Users can select a membership and optional services to calculate a sample monthly price.

### Booking Form

The booking form validates required fields and displays a confirmation message.
